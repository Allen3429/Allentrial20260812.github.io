# ScamShield MEGA 2026｜《換一條線，真相就現形》

> **臉可以假，聲音可以假；驗證通道不要交給對方。**

## 參賽創意

### 片名

**《換一條線，真相就現形》**

### Logline

當一個擁有主管臉孔與聲音的 AI Avatar 催促主角立刻匯款，主角不必在十五秒內判斷它是真是假；他只需先停下、換到自己掌控的通道，再獨立查證。

### 核心防詐行動

1. **停**：停止匯款、點擊與交付 OTP，先中斷攻擊者控制的節奏。
2. **換**：離開對方提供的電話、連結與郵件串。
3. **查**：使用自己找到的官方電話、原本保存的聯絡人或正式流程查證。

疑似詐騙、尚未匯款時，可撥 **165 反詐騙諮詢專線**；緊急情況、已受害或需要立即報案時，撥 **110 報案專線**。兩支電話都會在影片旁白與畫面中清楚呈現。

## 建議成片

- 目標長度：**4 分 20 秒**
- 規格：橫式 16:9、1920×1080 以上
- 形式：劇情式數位廣告 × Live AI Avatar × 互動網站實錄
- 主張：**不是教觀眾憑外觀抓假臉，而是教他們在任何外觀下執行可驗證的流程。**

導演模式內建八幕計時、旁白提詞、畫面指示、字幕安全區與全螢幕播放：

1. 十五秒壓力來電
2. 同一張臉、三種可信身分
3. 供應商帳戶突然變更
4. BREAK THE SPELL
5. 停、換、查
6. 金融素養與詐騙紅旗
7. 165／110 求助方式
8. 品牌片尾

## 安全原則

競賽版仍是 defensive-by-construction：

- 不生成自由形式詐騙腳本
- 不複製真實人物臉孔或聲音
- 不顯示真實帳戶、OTP、QR code 或可付款目的地
- 不提供電話、簡訊、LINE、Email 等外送能力
- 每一幕都回到停止、換線、獨立驗證或及時止損
