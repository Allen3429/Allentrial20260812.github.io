# Entero7｜第一輪真實需求驗證

## 最新需求訊號
- 疾管署2026/9/8：8/30–9/5腸病毒門急診8,475人次，較前週7,199人次上升17.7%。
- 2026年累計7例腸病毒重症、含1例死亡。
- 社區近期流行以克沙奇A6型為主，其次D68與A16；D68可主要表現為發燒、流鼻水、咳嗽，不一定有典型手足口症。
- 5歲以下是重症高風險群；確診後一週內特別觀察嗜睡／意識不清／活力不佳／手腳無力、肌抽躍、持續嘔吐、呼吸急促或心跳加快。
- 酒精對腸病毒效果有限；疾管署常用500 ppm含氯漂白水示例為10L清水＋100mL市售家庭漂白水。

## 小問題
衛教資訊很多，但家庭照顧時容易漏三件事：每天真正檢查重症前兆、D68像感冒時不因沒有水泡而自行排除、清消不要只用酒精。

## MVP
- 4個重症前兆快速勾選，任一命中直接顯示儘速送大醫院。
- 7天觀察板只存在localStorage。
- D68非典型症狀提醒。
- 500 ppm清消示例與酒精效果有限提醒。
- 確診在家休息、避免接觸其他嬰幼兒。
- 返校規則不做全國一刀切。
- 不收姓名、生日、學校、住址、病歷或照片。

## 第一輪硬門檻
- [ ] 80個獨立使用者
- [ ] 50人完成觀察板至少1次
- [ ] 30人複製照顧交接卡或打開官方資訊
- [ ] 20個家庭改正只用酒精的清消方式
- [ ] 15個家庭連續至少3天勾選重症前兆檢查
- [ ] 10個家庭真的完成生病在家休息／避免接觸其他幼兒
- [ ] 若出現重症前兆，追蹤是否真的送醫或打1922（不收醫療細節）
- [ ] 至少5個可重複照顧摩擦點
