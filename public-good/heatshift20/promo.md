# HeatShift 20｜營造／道路／外送／農事班前外展素材

【36°C不是只多喝一瓶水：戶外工作要把熱危害真的排進班表】

今天屏東有36°C以上黃色高溫燈號。
職安署第三版指引有幾個很容易漏的規則：

1. 先看官方「高氣溫作業防護資訊網」的熱危害級別，不只看氣溫。
2. 原本第1–3級，如果在陽光直接照射下工作，或穿不透氣厚重／抗滲透防護衣，要升一級處理。
3. 重體力作業每小時至少20分鐘充分休息。
4. 補水不要等口渴：官方建議每15–20分鐘150–200mL；受作業限制時至少每小時2–4杯。
5. 第4級不是「多喝水就好」：原則避免戶外作業；必要時要有遮陽、降溫、陰涼休息場所、飲水和緊急應變。
6. 意識混亂、昏迷、抽搐、呼吸困難或疑似熱中暑 → 119＋立即降溫。
