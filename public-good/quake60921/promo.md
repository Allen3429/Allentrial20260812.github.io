# Quake60 921｜家庭群／宿舍／社區外展素材

【9/21 09:21不要只看地震演練警報：真的練60秒】

今年國家防災日地震速報演練：
2026/9/21 上午9:21

收到演練警報時：
趴下 → 掩護 → 穩住
室內不要急著往外衝或搭電梯。

但真正有用的是警報後再多做5分鐘：
1. 抬頭找「會倒、會掉、會飛」的東西。
2. 看有沒有家具一倒就把門口／走道堵死。
3. 今天先固定或移動1件最危險的東西。
4. 家人約好失聯時怎麼聯絡、在哪種公共安全地點集合。
5. 別把「一個避難包」當全部防災：最新全民安全指引是居家至少7天物資；個人撤離包1–3天。
6. 家庭飲用水基線：每人每天至少3公升。
