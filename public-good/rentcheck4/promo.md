# RentCheck 4｜學生／新鮮人租屋社群外展素材

【開學租屋：看到「人在外地，我寄鑰匙給你」先不要覺得很方便】

警方近期示警新手法：
假房東說人在外地 → 寄鑰匙讓你自行看房 → 傳仿冒超商物流頁 → 用「實名認證」叫你操作網銀／匯款。

付款前只做四步：
1. 停：先付訂金才看房、寄鑰匙、外部實名認證／操作網銀 → 先停止付款。
2. 看：一定實際看屋，確認電表、屋況、逃生與設備。
3. 查：核對出租人身分＋有權出租證明；代理／轉租要看授權或合法轉租依據。
4. 簽：用內政部最新版住宅租賃契約核對；按度計電費不得超過該電費單「當期每度平均電價」。
