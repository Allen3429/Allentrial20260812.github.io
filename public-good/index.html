Public Good Lab · Taiwan · 2026

不是「做出網站」就算完成。
要有人真的用。

所有公開專案用同一套驗證漏斗：獨立瀏覽器 → 完成核心操作 → 留下回饋 → 自我確認已採取現實行動。沒有使用，就只是原型。

統計方式：不收姓名、Email、精確位置或健康資料。以瀏覽器 localStorage 做近似去重，再用公開 counter API 計數。數字只做 MVP 需求驗證，不作財務、稽核或官方統計。

驗收標準

統一規則：「已部署」≠「已驗證」。每個工具至少要看得到獨立使用者、完成核心操作、回饋與現實行動；若持續沒有需求訊號，就優先改推廣／入口，仍無使用則停止投入。
