Public Good Lab · Taiwan · 2026

不是「做出網站」就算完成。
要有人真的用。

每個公開專案現在都用同一套驗證漏斗：獨立瀏覽器 → 完成核心操作 → 留下回饋 → 自我確認已採取現實行動。沒有使用，就只是原型；有使用、有回饋、有行動，才算被驗證。

統計方式：不收姓名、Email、精確位置或健康資料。以瀏覽器 localStorage 做「獨立瀏覽器」近似去重，再透過公開無登入 counter API 統計核心操作與回饋。數字適合MVP需求驗證，不作財務、稽核或官方統計用途；自己測試與公開counter遭惡意點擊仍可能造成偏差。

驗收標準

目前統一規則：「已部署」≠「已驗證」。每個工具至少要看得到獨立瀏覽器、完成核心操作、回饋人數與現實行動；第一輪若完全無人使用，就優先改推廣／入口，仍無需求訊號則停止投入。已完成但尚未公開的舊原型，在重新核對時效與資料來源後才會加入LIVE區，加入時就必須自帶這套追蹤。
