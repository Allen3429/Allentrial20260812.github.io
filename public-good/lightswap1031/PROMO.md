# LightSwap 1031｜家庭／宿舍／社區外展素材

【家裡還有省電燈泡、螢光燈管？9/9–10/31換LED前先做一件事：舊燈不要丟垃圾車】

環境部115年「照明亮久久」已開跑。

官方估算：
- 16W LED取代23W省電燈泡
- 每顆一年約省100元電費
- 每顆一年約少10公斤碳排
- 20顆約省2,000元／年、減少200公斤碳排

換完更重要：
1. 用新品紙盒／紙套或堅固紙箱包好舊燈。
2. 避免燈管碰撞破損。
3. 不要混入一般垃圾。
4. 交照明販賣通路、清潔隊資源回收車或合法回收機構。
5. LED燈管／燈泡壞掉也要回收。

今年合作包含：
光南、振宇五金、特力屋、愛買；舞光、東亞、亮博士、樂亮LED、飛利浦；PChome、momo、東森購物。
各家優惠不同，以官方活動頁為準。
