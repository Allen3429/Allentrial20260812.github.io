隱私、儲存與數字限制

表單與結果留在頁面記憶體，沒有伺服器儲存，也不放進分享網址。自行匯出後，檔案由你保管。僅同意偏好與計數去重標記使用 localStorage；不建立跨站追蹤碼。主機 GitHub Pages 及選用的計數供應商仍可能接收 IP 與連線紀錄，不能稱完全匿名。點「載入公開計數」會連線至第三方。

拒絕計數不影響工具。同意後僅收工具代號、事件種類、限定的來源分類和回饋選項。文字回饋另在 GitHub 公開發送；這裡不會自動送出。清除本機資料不會刪除已匯總的公開計數，並可能導致之後重算。多裝置、封鎖儲存、斷線或公開 API 被濫用會影響準確性。

方法與來源

大部分工具是使用者輸入上的算術、排序與文字範本；並非專業諮詢或生成式 AI。所有自訂評分、備用比例及規劃假設均在工具中標示。排班採貪婪法，須人工確認且不保證最佳解。
