# KeyTrap 165｜新生／租屋社團外展素材

【開學季最新租屋詐騙｜「我人在外地，可以寄鑰匙給你」先不要點】

刑事局2026/9/6公布新手法：
1. 社群平台刊登低於行情、裝潢精美租屋
2. 假房東說人在外地，無法親自帶看
3. 說可以用超商物流寄鑰匙，讓你自己看房
4. 傳仿冒物流／交貨便網站
5. 用「實名認證」引導操作網銀、匯款

警方揭露已有社會新鮮人損失5萬多元。

記住：
- 超商物流不會為「實名認證」要求你匯款／操作網銀
- 現場看屋
- 核對出租人／代理人身分
- 簽約後再付款
- 可疑就撥165
