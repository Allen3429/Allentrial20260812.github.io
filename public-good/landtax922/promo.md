# LandTax 922｜家人／房產／里鄰群外展素材

【自住房不是自動地價稅2‰｜今年買房、繼承、受贈的人9/22前特別要看】

115年地價稅：
- 一般用地：10‰–55‰
- 符合自用住宅用地：2‰
- 9/22前申請，核准後今年就能用；逾期原則上116年才適用

最容易漏的情況：
1. 今年買房、受贈、繼承或信託取得土地
   → 原所有權人的2‰不會自動延續，新所有權人要重新申請。
2. 曾因全家遷出／設籍人死亡形成空戶，後來再遷回
   → 也要重新申請。
3. 已經核准，而且所有權、用途、設籍完全沒變
   → 通常不用每年重複申請。
4. 115/7/23新令釋：同性配偶的直系親屬設籍，也平等適用自用住宅優惠。

基本條件：
- 本人／配偶／直系親屬在該住宅設籍
- 房屋權屬符合規定
- 沒有出租／供營業（部分使用請另確認）
- 都市土地優惠範圍最多300㎡；非都市700㎡
