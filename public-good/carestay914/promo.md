# CareStay 914｜照顧者／機構社工外展素材

【住宿式機構補助9/14開始申請｜今年不是再等全年住滿180天】

衛福部2026/9/10公布長照3.0新制：

1. 住宿式機構住民符合「長照需要4級以上」或「中度以上身障證明」
→ 每月最高15,000元
→ 全年最高180,000元
→ 追溯自2026/1/1

2. 2023/1/1以前已入住且持續入住的既有住民
若未評估或未達長照4級
→ 每月最高5,000元

3. 本來已領「身障住宿式照顧費用補助」且為中度以上身障
→ 原制度不必換
→ 另可申請每月5,000元加碼

今年最大的改變：
從「全年累積住滿180天」改成「按月認列」。
31天月份住16天、30天15天、2026年2月14天，就可認列1個月。

過渡保障：
如果2025年曾核定領12萬元，而且2026年1–8月實際入住達180日
→ 1–8月保障12萬元
→ 9月起按月新制算

申請自2026/9/14開始。
