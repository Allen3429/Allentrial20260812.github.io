# PhoneExit｜剛換新機／社團／3C社群外展素材

【換新手機先別把舊機直接交出去｜5步資料安全退出】

新機換機潮開始，但很多人的舊手機因為「怕個資外洩」最後一直留在抽屜。

環境部資料顯示：
- 臺灣每年約賣出500萬支手機
- 舊手機回收率約12%
- 超過5成民眾把舊機放在家裡
- 個資外洩疑慮是重要原因之一

交出去前先做：
1. 在新機／電腦實際打開重要照片、聊天備份、驗證器資料，確認不是只有「顯示備份成功」。
2. 移轉SIM/eSIM，取出實體SIM與microSD。
3. Android轉售／送人前先移除Google／品牌帳號；iPhone準備好Apple帳號密碼。
4. 用系統正式「恢復原廠／清除所有內容和設定」。iPhone的「重置所有設定」不會刪照片、訊息、App或文件。
5. 重開後確認回到初始設定畫面，再交給品牌／販售通路／正式回收。

如果手機螢幕壞掉或不能開機：
- 資料還沒備份 → 先處理資料救援／維修
- 資料已備份但不能抹除 → 問正式回收通路「你們怎麼處理資料防洩漏？」
- 不要自行拆、鑽、刺穿或壓壞鋰電池
