# HomeLoan 930｜第一輪真實需求驗證

## 問題
115年度自購、修繕住宅貸款利息補貼自2026/9/1 09:00至9/30 17:00受理。
全國預計自購4,000戶、修繕2,000戶，共6,000戶。
官方採評點排定優先順序，不是先到先得；115年度所得／財產標準已更新，分10種區域標準。

這輪不重做政府完整資格審查，只驗證：
- 是否有人因錯過9/1第一天，以為已沒機會；
- 是否不知道該選自購或修繕；
- 是否沿用舊年度所得／財產門檻；
- 是否以為辦過青安就不能搭配；
- 是否看到規則複雜就完全沒進官方資格檢視。

## MVP
1. 9/30 17:00動態倒數。
2. 自購／修繕30秒路由。
3. 所得財產不在本頁輸入，直接導向官方資格檢視。
4. 青安可搭配的官方提醒。
5. 政策優惠貸款額度量級顯示。
6. 9/25本機ICS提醒。
7. Public Good Lab匿名驗證＋Issue #54。

## 第一輪成功門檻
- 40個獨立使用者
- 25人完成路徑卡
- 15份非敏感流程回饋
- 10人真的進官方資格檢視或正式線上申請
- 8人完成備件／致電／送件至少一項
- 至少5個可重複摩擦點
- 至少3名原本以為「錯過9/1／青安不能搭／標準太複雜」者，最後進入官方流程

## 訪談
1. 你原本知道不是先到先得嗎？
2. 你原本知道青安可與此補貼搭配嗎？
3. 你是卡在自購vs修繕、10區域所得財產、文件、線上系統，還是期限？
4. 官方資格檢視有沒有直接回答你的問題？
5. 最後有沒有送件？沒有的第一個原因是什麼？
