# Ready921｜家人／室友／班群外展素材

【9/21 09:21 地震演練前｜別只練趴下，先算你家能撐幾天】

新版《臺灣全民安全指引》建議：
- 居家儲備：至少7天
- 飲用水：每人每天至少3公升
  → 1人7天至少21L
  → 2人至少42L
  → 4人至少84L
- 個人緊急避難包：1–3天份
- 物資每半年檢查

居家儲備和避難包不是同一包：
家裡能留守時用7天物資；
住家不安全、需要離開時，才背1–3天避難包。

家人還要約好：
1. 集合點A
2. 第一點不能去時的集合點B
3. 一名外地聯絡角色
4. 誰帶包、誰照顧孩童／長者／毛孩
