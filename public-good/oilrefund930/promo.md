# OilRefund 930｜家庭／社區／消費者群組外展素材

【家裡還有泰山油品？9/30退款截止前先查批號；沒有紙本發票也先別放棄】

中聯油品事件後，行政院消保會目前整理的泰山退款方案受理到 2026/9/30。

先做這幾件事：
1. 用食藥署官方清單查產品／批號／有效日期。
2. 原購買通路願意退款 → 優先走原通路，通常比較快。
3. 有紙本發票／電子發票／訂單／會員購買紀錄 → 先保存。
4. 沒有發票，但能證明 2026年4–6月實際購買，而且商品還在／已開封 → 仍可打泰山 0800-079080 問專人親訪與商品退款安排。
5. 官方目前寫明：無論問題產品有無使用，都可依方案處理。
