# SweatPass 300｜運動／學生／跑團社群外展素材

【揮汗有禮｜截圖傳錯不能改，送出前30秒先檢查】

運動部「揮汗有禮」現在總量已加碼到300萬份，但官方規則有幾個很硬的點：

1. 每週一～週日是一個週期。
2. 只能用「當週」的運動紀錄，而且當週就要上傳。
3. 送出後不能修改、更換或自行補件。
4. 截圖要清楚看到日期（月、日）＋達標數值。
5. 不要裁切／拼貼；要用運動App原始紀錄或正式完賽證明。
6. 不能只傳健身房／運動中心進出紀錄。
7. 不能修圖、變造或AI生成申請紀錄。

門檻擇一：
- 單次運動30分鐘
- 單日8,000步
- 單次健走／跑步5公里
- 自行車15公里
