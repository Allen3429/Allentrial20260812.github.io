# NIAS Done｜第一輪真實需求驗證

## 近期需求訊號
- 疾管署115年度校園專區已更新NIAS家長線上簽署流程、操作影片與多語意願書。
- 近期各校已陸續公告自己的簽署時程；例如臺北市中崙高中9/9公告，家長簽署預定9/21–9/26，並特別提醒「同意或不同意在校接種，都請上NIAS簽署」，且須看到「意願書填寫已完成」才算完成。
- 彰化大城國小9/3公告10/20校園接種、10/15簽署截止，也提醒截止前可修改接種意願。
- NIAS近兩年校園流感意願調查覆蓋率約95%，已成為各級學校校園疫苗意願調查、統計及造冊核心工具。
- 同期國內流感已於9/8進入流行期，因此「完成行政意願流程」的時效性提高，但是否接種仍屬家長／學生與醫療專業決策。

## 要驗證的小問題
不是「家長知不知道有流感疫苗」，而是：
1. 每校截止日不同，容易漏。
2. 以為「不同意」就不用填。
3. 表單做到一半，沒有看到完成頁就離開。
4. 家中多個孩子／多校時程混淆。
5. 學校專屬NIAS連結容易被群組訊息淹沒。

## MVP
1. 手動填學校自己的截止日與接種日。
2. 3步防漏：找到專屬連結 → 完成意願簽署 → 看到完成頁。
3. 下載截止日前1天與接種日 `.ics` 提醒。
4. 不問、不存同意／不同意。
5. 導向疾管署校園專區與官方NIAS。
6. 不收學生個資、學校、病史或私人連結。
7. Public Good Lab匿名量測＋Issue #68。

## 第一輪硬門檻
- 40個獨立使用者
- 25人完成3步防漏檢核
- 20人下載截止提醒
- 15人點疾管署校園專區／官方NIAS
- 10份非敏感流程回饋
- 8個家庭真的完成校方要求的NIAS意願簽署
- 至少3名原本以為「不同意就不用填」者完成流程
- 至少5個可重複的NIAS流程摩擦

## 3分鐘訪談
1. 學校是透過什麼管道發NIAS連結？
2. 你原本知道同意／不同意都可能要依校方要求完成簽署嗎？
3. 最容易卡在哪：找連結、登入資料、簽名、完成頁、截止日？
4. 你家有兩個以上孩子時，會不會混淆截止日？
5. 加入行事曆提醒有沒有幫助？
6. 最後是否真的完成學校要求的簽署？
