# NIAS Done｜家長群／健康中心外展素材

【115學年度校園流感疫苗｜NIAS不要做到一半】

今年各校會依自己的時程發出 NIAS 校園流感疫苗意願書。

容易漏的不是「要不要打」，而是行政流程：
1. 每校截止日不同，要看自己學校公告
2. 同意或不同意在校接種，都可能需要依校方要求完成線上意願簽署
3. 真正完成不是「有點進去」，而是做到最後看到「意願書填寫已完成」或校方等效完成畫面
4. 真正簽署請用學校提供的專屬 QR code／連結

NIAS Done 可以：
- 記學校自己的簽署截止日
- 做3步防漏
- 下載截止日前1天提醒
- 不保存孩子姓名、身分證、學校、疫苗意願或健康資料
